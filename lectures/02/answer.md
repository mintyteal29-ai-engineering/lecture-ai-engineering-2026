## 宿題

- 取り組んだレベル：基礎
- 変えた設定やデータ：ケース1：エポックを20->40、ケース2：lr 0.0002->0.001での検証
- 結果（比較表や数字）：
　　ケース1
   - 学習前：`format_rate` =　0.09523809523809523 / `content_rate` =　0.0
   - 学習後：`format_rate` =　1.0  / `content_rate` =　0.9047619047619048
     
   ケース2
   - 学習前：`format_rate` =　0.09523809523809523 / `content_rate` =　0.0
   - 学習後：`format_rate` =　1.0  / `content_rate` =　0.9047619047619048

  formatとcontentの結果は変わらなかった。

　ケース1より。
  講義でも言われていた、14件データに対する20エポックがすでに過学習気味ということで合ったので、
  40エポックに学習をさらに追加したが、すでに飽和状態になっていた。
  Training Lossもすでに0.01台だったため、これ以上Lossを減らす余地がないし、
  フォーマットはすでに100%なので、これ以上改善できないし、知識はエポックでは獲得できないためcontent_rateも改善せず、
  回数が増えた分のコストが増えただけであった。  

  ケース2より。
  学習率を高めたことで、step20の段階でTraining Lossが下がり、破壊されずに学習ができた。
  退化はなく、Lossの観点ではわずかに上昇した。

- ファインチューニングが向く場面・向かない場面についての考察：
フォーマット自体は、9%=>100%と改善しているが、content_rateは、0%=>90%という形で、100%にはならない。
形式やフォーマットを最適化するには、ファインチューニングが向いているが、
学習した実データに基づいた回答をするにはファインチューニングだけでは不足しているため、他のアプローチも必要か。
